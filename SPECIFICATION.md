# Degg Switch — SPECIFICATION

## 1. Назначение

Переключатель входов — аналог ImpactSwitch из Impact-Pack, но **без бага с удалением входов**. Позволяет подключить несколько источников данных любого типа и выбрать числом `select`, какой из них передать на выход.

## 2. Файлы

| Файл | Назначение |
|------|-----------|
| `deg_switch_node.py` | Python-класс ноды `DeggSwitch` — 20 lazy-входов, `check_lazy_status` |
| `web/js/deg_switch.js` | LiteGraph-расширение: динамические входы, подпись на выходе |
| `__init__.py` | Экспорт маппингов, `WEB_DIRECTORY` |

## 3. Python: класс DeggSwitch

### INPUT_TYPES

| Поле | Тип | По умолчанию | Описание |
|------|-----|-------------|----------|
| `select` | `INT` | `1` | Номер входа, который будет выведен на выход (1–20, шаг 1) |

### optional (20 шт, lazy)

| Поле | Тип | Описание |
|------|-----|----------|
| `input_1` … `input_20` | `*` (any) | Входы для подключения данных. Lazy — вычисляются только по необходимости. |

### hidden

- `unique_id` — ID ноды для идентификации в графе.

### OUTPUT

- `RETURN_TYPES = ("*",)` — тип на выходе: любой (определяется подключёнными данными).
- `RETURN_NAMES = ("output",)` — имя выхода.

### Логика

- `check_lazy_status(select, ...)` — запрашивает только выбранный вход, остальные lazy-входы не вычисляются (экономия ресурсов).
- `process(select, ...)` — возвращает значение выбранного входа. Если вход не подключён — вернёт `None`.

### 4.2. Динамические входы

**Принцип работы:**

| Событие | Результат |
|---------|-----------|
| Нода создана | Только `input_1` |
| Провод к `input_N` | Появился `input_{N+1}` (если N < 20) |
| Отключён `input_N` | Все пустые входы с номером > N удалены. `input_N` остаётся пустым |
| Загружен воркфлоу | Входы автоматически восстанавливаются по сохранённым соединениям |

**Функции:**

- `findLastConnected(node)` — находит последний подключённый вход.
- `rebuildInputs(node)` — перестраивает входы: удаляет лишние хвостовые, добавляет недостающие.
**Защита от бага ImpactSwitch:**

В оригинальном ImpactSwitch удаление входов блокировалось проверкой `stackTrace`:
```javascript
if (!stackTrace.includes('LGraphNode.connect')) {
    this.removeInput(index);  // НИКОГДА не срабатывало
}
```

В DeggSwitch используется **чистая логика** без хаков:
- `rebuildInputs` идемпотентна — безопасно вызывать многократно.
- `setTimeout(0)` в `onConnectionsChange` — чтобы не модифицировать входы во время обработки соединения.
- Алгоритм просто находит последний подключённый вход и удаляет всё, что за ним.

### 4.3. Лимит

Максимум **20 входов** (`MAX_INPUTS = 20`). `select` ограничен текущим количеством входов.
